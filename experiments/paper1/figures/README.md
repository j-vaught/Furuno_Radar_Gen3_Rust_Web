# Paper 1 figure kit

The empirical sources use the first live capture at
`/Volumes/MacApplications/Radar_papers/data/live/macos-recordings/20261014_042023`
and its archived UDP payloads. `tools/derive_data.py` records source paths and
SHA-256 digests while producing the compact JSON inputs consumed by Typst.

Compile from this directory with `./build-figures.sh`. Final PDF/PNG pairs are
written to `output/`. To populate future figures from the analyzer, pass its
`figure_data` directory as the first argument and an optional Doppler audit JSON
as the second argument. For example, `./build-figures.sh
/path/to/figure_data /path/to/doppler_bit_audit.json`. The
production names are `fig_capture_contract`, `fig_target_geometry`,
`fig_live_receive`, and `fig_live_codes_support`. The protocol templates are
`fig_stationary_repeatability`, `fig_setting_transition`,
`fig_settings_coverage`, `fig_setting_response`, `fig_bit_planes`, and
`fig_range_bearing_residuals`.
The CeTZ diagrams use square corners, New Computer Modern, garnet only as an
accent, and filled stealth arrows. The Lilaq plots retain the package default
palette.

Figures 1--4 are ready from measured data. The future templates import JSON
files generated by `tools/adapt_toolkit.py` from the analyzer's
`figure_data/*.csv` outputs. They render quantitative Lilaq plots when those
files contain data and intentionally render a clearly labeled preview while
inputs are empty. No unavailable result is plotted. `fig_settings_coverage.typ`
adds the settings command/readback coverage panel required by the functional
test sequence.
