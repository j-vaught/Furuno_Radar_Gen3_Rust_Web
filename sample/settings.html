Pattern Loader

Upload a pattern file or paste steps directly. Format: range,gain,pulse,rezboost,speed,interp,repeat separated by semicolons.

Pattern format

range (0-21), gain (0-99), pulse (0=S1 … 5=L), rezboost (0=Off…3=High), speed (0=Lo,1=Hi,2=Auto), interp (0=2048,1=4096,2=8192,3=1024,4=720,5=Off), repeat (sweeps at this setting).

Separate steps with semicolons. Example:
0,20,0,0,2,5,2; 0,25,1,1,2,0,3

For files, use one step per line or semicolons; both are accepted.

Queue Patterns run in the order shown.
